# Superstore Sales Analysis

## Overview
This project analyses the Kaggle Superstore Sales dataset using PostgreSQL.
The raw data was cleaned and split into five tables: customers, geography,
orders, order_items, and products.

## Data Source
Kaggle Superstore Sales Dataset — https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting

## What I Investigated
- Which product category and subcategory drives the most revenue
- Sales performance across different regions
- Top 10 customers by total sales
- How discounts affect sales
- Monthly and yearly sales trends
- Month on month sales growth

## SQL Concepts Used
- Data cleaning and validation
- Multi-table JOINs
- GROUP BY and aggregation
- CASE WHEN
- Window functions (RANK, LAG, running totals)
- Time series analysis using EXTRACT()
